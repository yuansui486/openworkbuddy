# 国际运费计算

## 适用场景
报价前的成本核算、物流方案选择、交期评估、Incoterm 决策。

## 核心任务
根据货物特征和客户需求，**对比不同运输方式**，推荐性价比最优或时效最快的方案。

## 前置信息收集

### 必需参数（缺一不可）
```markdown
1. **货物信息**
   - 重量（实际重量 Gross Weight）：单位 kg
   - 体积（长 × 宽 × 高）：单位 cm 或 m³
   - 数量：箱数
   - 货物性质：普货 / 带电 / 液体 / 危险品

2. **起运地 Origin**
   - 国家、城市、邮编（如：中国深圳 518000）
   - 是否需要上门提货

3. **目的地 Destination**
   - 国家、城市、邮编（如：美国洛杉矶 90001）
   - 是否需要送货上门

4. **运输要求**
   - 预算限制（如有）
   - 交期要求（普通 / 加急）
   - 保险需求（是否投保）
```

### 可选参数
- 货值（用于保险计算）
- 是否需要报关代理
- 是否拼箱（LCL）或整柜（FCL）

## 计费重量计算

物流行业按**体积重量 vs 实际重量取大者**计费。

### 体积重量公式
```
体积重量 (kg) = 长(cm) × 宽(cm) × 高(cm) ÷ 体积系数

体积系数：
- 海运/卡车：通常不单独算体积重，按立方米 (CBM) 计费
- 空运：6000 (即 1 m³ = 166.67 kg)
- 快递：
  - DHL/FedEx/UPS：5000 (1 m³ = 200 kg)
  - EMS：8000 (1 m³ = 125 kg)
```

### 示例计算
```markdown
**货物**：100 箱 USB 充电线
**每箱尺寸**：50 × 40 × 30 cm
**每箱实际重量**：10 kg

**总实际重量** = 100 × 10 = 1,000 kg

**单箱体积** = 0.5 × 0.4 × 0.3 = 0.06 m³
**总体积** = 100 × 0.06 = 6 m³

**空运计费重量** = 6 m³ × 166.67 kg/m³ = 1,000 kg
（与实际重量相等）

**快递计费重量** = 6 m³ × 200 kg/m³ = 1,200 kg
（取体积重量）
```

**结论**：该货物空运按 1,000 kg，快递按 1,200 kg 计费。

## 运输方式对比

### 1. 海运 Sea Freight（经济但慢）

**适用场景**：
- 大批量货物（> 1 CBM 或 > 500 kg）
- 对时效要求不高（可接受 3-6 周）
- 重货（实际重量远大于体积重量）

**费用组成**：
```
海运费 = 基础运费 + 附加费 + 目的港费用

基础运费：
- 整柜 FCL（20GP/40GP/40HQ）：按柜计费
- 拼箱 LCL：按 CBM 计费

附加费：
- 燃油附加费 BAF
- 旺季附加费 PSS（通常 9-11 月）
- 目的港拥堵费 PCS
- 安全附加费 EBS

目的港费用：
- 码头操作费 THC：$300-800 / 柜
- 文件费 DOC：$50-150
- 清关费：$150-500
- 送货费（如 DDP）
```

**参考价格**（2026 年）：
| 航线 | 20GP | 40GP | 40HQ | 时效 |
|---|---|---|---|---|
| 中国 → 美西 | $2,500-3,500 | $3,500-5,000 | $4,000-5,500 | 18-25 天 |
| 中国 → 美东 | $3,500-5,000 | $5,000-7,000 | $5,500-7,500 | 28-35 天 |
| 中国 → 欧洲 | $3,000-4,500 | $4,500-6,500 | $5,000-7,000 | 30-40 天 |
| 中国 → 东南亚 | $500-1,200 | $800-1,800 | $1,000-2,000 | 7-15 天 |

**拼箱 LCL 价格**：$80-150 / CBM（含基本费用，不含目的港杂费）

**整柜装载量参考**：
- 20GP：28-33 CBM，最大载重 21-24 吨
- 40GP：56-68 CBM，最大载重 24-26 吨
- 40HQ（高柜）：68-76 CBM，最大载重 26-28 吨

### 2. 空运 Air Freight（快但贵）

**适用场景**：
- 中小批量（< 500 kg 建议快递，> 500 kg 考虑空运）
- 有明确交期要求（1-2 周内）
- 货值高、体积小的产品（电子产品、样品）

**费用组成**：
```
空运费 = 运费 ($/kg) × 计费重量 + 附加费 + 目的地费用

运费阶梯：
- +45 kg：基础价（最贵）
- +100 kg：-10% 左右
- +300 kg：-20% 左右
- +500 kg：-30% 左右
- +1000 kg：-40% 左右

附加费：
- 燃油附加费：通常 20-40% 的运费
- 安检费：$0.3-0.8 / kg
- 旺季附加费（11-12 月）

目的地费用：
- 目的港提货费：$100-300
- 清关费：$150-500
```

**参考价格**（2026 年，含燃油）：
| 航线 | +45 kg | +100 kg | +500 kg | +1000 kg | 时效 |
|---|---|---|---|---|---|
| 中国 → 美国 | $8-12 | $7-10 | $5-8 | $4-6 | 5-7 天 |
| 中国 → 欧洲 | $7-11 | $6-9 | $4.5-7 | $3.5-5.5 | 5-8 天 |
| 中国 → 东南亚 | $4-7 | $3-6 | $2.5-5 | $2-4 | 3-5 天 |

### 3. 国际快递 Express（最快最贵）

**适用场景**：
- 小件急货（< 100 kg）
- 样品、文件、小批量补货
- 需要门到门服务 + 全程跟踪

**主流快递公司**：
| 快递 | 优势 | 劣势 | 适用 |
|---|---|---|---|
| **DHL** | 速度最快，欧洲线路强 | 价格最贵，查验严 | 商务文件、欧美急件 |
| **FedEx** | 美国线路快，服务好 | 价格高 | 美国急件、高货值 |
| **UPS** | 美国本土快，系统稳定 | 偏远地区弱 | 美国商业件 |
| **TNT** | 欧洲性价比高 | 其他地区慢 | 欧洲线路 |
| **EMS** | 中国邮政，清关优势 | 速度慢，丢件率高 | 低货值、敏感货 |
| **顺丰国际** | 东南亚快，中文服务 | 覆盖范围有限 | 东南亚、日韩 |

**参考价格**（首重 0.5 kg，续重 0.5 kg）：
| 目的地 | DHL | FedEx | UPS | EMS | 时效 |
|---|---|---|---|---|---|
| 美国 | ¥220 + ¥60 | ¥200 + ¥55 | ¥210 + ¥58 | ¥140 + ¥40 | 3-5 天 / 7-10 天 (EMS) |
| 欧洲 | ¥230 + ¥65 | ¥220 + ¥60 | ¥240 + ¥70 | ¥150 + ¥45 | 3-5 天 / 7-12 天 (EMS) |
| 东南亚 | ¥150 + ¥40 | ¥140 + ¥38 | ¥160 + ¥45 | ¥100 + ¥30 | 2-4 天 / 5-8 天 (EMS) |

**体积限制**：
- 单边最长：120 cm
- 周长（最长边 + 2×宽 + 2×高）：< 300 cm
- 单件重量：< 70 kg（超重需走货运）

### 4. 铁路 Railway（新兴选择）

**中欧班列**：
- 时效：15-20 天（比海运快，比空运便宜）
- 价格：约为空运的 1/4，海运的 2 倍
- 适用：中国 ↔ 欧洲，整柜货物

## 方案对比与推荐

### 决策矩阵

| 货物特征 | 推荐方式 | 理由 |
|---|---|---|
| < 50 kg，急 | 快递 | 时效最快，门到门 |
| 50-500 kg，急 | 空运 | 比快递便宜，比海运快 |
| > 500 kg，不急 | 海运拼箱 LCL | 性价比最高 |
| > 15 CBM | 海运整柜 FCL | 单位成本最低 |
| 超高货值 | 空运 + 保险 | 降低资金占用 |
| 超重货（实重 >> 体积） | 海运 | 海运不按体积重计费 |

### 示例计算与推荐

**场景**：1,000 kg USB 充电线，6 CBM，深圳 → 洛杉矶

#### 方案 1：海运拼箱 LCL
```
运费：6 CBM × $120/CBM = $720
目的港费用：THC $150 + DOC $80 + 清关 $200 = $430
总费用：$720 + $430 = $1,150
时效：20-25 天
单位成本：$1.15 / kg
```

#### 方案 2：空运
```
运费（+1000 kg 档）：1,000 kg × $5/kg = $5,000
目的港费用：提货 $200 + 清关 $200 = $400
总费用：$5,000 + $400 = $5,400
时效：5-7 天
单位成本：$5.40 / kg
```

#### 方案 3：快递（DHL）
```
首重 0.5 kg：¥220 = $30
续重：1,199.5 kg × ¥60/0.5kg = ¥143,940 = $19,992
总费用：约 $20,022
时效：3-5 天
单位成本：$20.02 / kg（按 1,200 kg 计费重量）
```

#### 推荐
```markdown
### 推荐方案：海运拼箱 LCL

**理由**：
- 成本最低：$1,150（比空运便宜 $4,250，节省 79%）
- 时效可接受：20-25 天（若非急单，完全够用）
- 货量适中：6 CBM 适合拼箱，不必整柜

**备选方案**：空运（如客户急需）
- 适用场景：补货、新品上市、节日促销前
- 额外成本：$4,250
- 时效优势：提前 15-18 天

**不推荐**：快递
- 成本过高（$20,022），不经济
- 1,200 kg 计费重量超出快递优势范围
```

## 附加费用说明

### 保险费
```
保险费 = 货值 × 保险费率

费率参考：
- 海运：0.2-0.5%
- 空运：0.1-0.3%
- 快递：通常包含基础保险（$100 以内免费，超出部分可加保）

建议：货值 > $5,000 建议投保
```

### 清关费用
```markdown
**自己清关 DIY**：
- 美国：ISF Filing $50 + Customs Bond $500（首次）+ Broker $0
- 时间成本高，适合有经验的

**代理清关**：
- 美国：$150-500 / 票
- 欧盟：€100-400 / 票
- 包含报关、商检、送货预约
```

### 目的地派送
```markdown
**港口/机场自提**：通常免费（需自己安排车辆）

**送货上门**：
- 美国：$100-500（根据距离和是否需要尾板车）
- 欧洲：€80-400
- 偏远地区：加收 50-100%
```

## 红线
- **不用过期价格**：运费波动大，必须标注报价日期和有效期
- **不隐藏附加费**：THC、DOC、清关费都要列明，不能只报基础运费
- **不混淆计费重量**：实重 vs 体积重要算清楚
- **不保证时效**：只能给"通常"或"预计"时效，天气、港口拥堵等不可控

## 质量标准
- 计费重量计算正确（实重 vs 体积重取大者）
- 至少对比 2-3 种运输方式
- 费用明细完整（不只给总价）
- 推荐方案有清晰理由
- 时效说明包含各环节（运输 + 清关 + 派送）

## 进阶：敏感货物处理

**带电产品**（内置锂电池）：
- 海运：需 MSDS、UN38.3 测试
- 空运：受限，部分航空公司拒载
- 快递：DHL/FedEx 可接，但需额外认证

**液体 / 粉末**：
- 通常只能走海运或专线
- 空运/快递对液体有严格限制（< 100ml）

**仿牌 / 侵权货**：
- 正规渠道无法运输
- 建议合规经营，不走灰色渠道
