# 报价单生成

## 适用场景
给客户出报价、询盘回复、投标文件准备、内部成本核算。

## 核心公式

```
总报价 = (单位成本 + 单位运费) × 数量 × (1 + 利润率) + 其他费用
```

每一项都要能拆开讲清楚，不许只给一个总价。

## 步骤

### 1. 收集报价要素（缺一项就问用户）
**必需信息**：
- **产品**：名称、规格、单位（piece/set/kg）
- **数量**：采购数量
- **单位成本**：出厂价/采购成本（含税或不含税要说明）
- **贸易条款 Incoterm**：FOB/CIF/CFR/EXW/DDP 等
- **目的地**：国家、城市、港口

**可选信息**：
- 利润率（默认 15-30%，根据行业调整）
- 付款方式（T/T、L/C、D/P）
- 交期（生产周期 + 运输时间）
- 包装要求
- 报价币种（默认 USD）

### 2. 成本拆解计算

#### 基础成本
```
产品成本 = 单位成本 × 数量
```

#### 运费估算（根据 Incoterm）
- **EXW（工厂交货）**：运费由买方承担，报价不含运费
- **FOB（装运港船上交货）**：加国内运输到港口 + 报关费
- **CIF/CFR（成本加运费/保险）**：加海运费 + 保险（CIF 才有）
- **DDP（完税后交货）**：加全程运费 + 目的国关税 + 清关费

**运费参考值**（需实际询价）：
- 国内到港口：¥500-2000 / 立方米
- 海运（中国→美国西海岸）：$800-2000 / 20GP 集装箱
- 空运：$4-8 / kg
- 快递：$8-15 / kg

#### 其他费用
- 包装费：特殊包装额外收费
- 认证费：CE、FDA 等测试费用分摊
- 样品费：首单可能包含样品制作
- 银行手续费：通常 1-2%

### 3. 定价策略

**目标利润率**（根据产品类型选择）：
- 标准品/低值易耗品：10-20%
- 定制品/中端产品：20-35%
- 高科技/高附加值：35-60%

**价格梯度**（鼓励大量采购）：
```
数量档位      单价       备注
1000-4999    $2.50     MOQ
5000-9999    $2.30     -8%
10000+       $2.10     -16%
```

### 4. 货币转换
如果客户要求非 USD 币种，调用 exchange-rate 插件：

```javascript
// 转换为目标货币
{
  amount: totalPriceUSD,
  from: "USD",
  to: "EUR" // 或 GBP, CNY 等
}
```

**必须注明**：
- 汇率：1 USD = X EUR
- 汇率日期：2026-11-23
- 有效期：报价单 15 天内有效（超期汇率可能变化）

### 6. 双语对照
外贸报价单建议**中英双语**，关键术语用英文：
- Quotation / 报价单
- Incoterm / 贸易术语
- Payment Terms / 付款方式
- Lead Time / 交货期

### 7. 输出检查
生成报价单后，自查：
- [ ] 所有金额精确到小数点后 2 位
- [ ] 总价 = 各项相加（验算一遍）
- [ ] Incoterm 与费用项匹配（FOB 不能包含海运）
- [ ] 币种统一（不要 USD 和 CNY 混用）
- [ ] 有效期明确标注
- [ ] 联系方式完整

## 常见 Incoterm 对比

| 术语 | 卖方责任截止 | 报价包含 | 适用场景 |
|---|---|---|---|
| **EXW** | 工厂交货 | 仅产品成本 | 买方有清关能力 |
| **FOB** | 装船前 | 成本 + 国内运输 + 报关 | 最常用，责任分明 |
| **CIF** | 装船前 | FOB + 海运 + 保险 | 买方方便，卖方控制物流 |
| **DDP** | 目的地交货 | 全部费用含关税 | 买方省心，卖方风险大 |

**默认推荐 FOB**，除非客户明确要求其他条款。

## 红线
- **不虚报成本**：给客户的报价可以加利润，但内部成本必须真实
- **不遗漏费用**：宁可列明"不含XX费"，也不要事后追加
- **不用过期汇率**：汇率必须是报价当天或前一工作日的
- **不混淆 Incoterm**：FOB 包含海运是错的，DDP 不含关税也是错的

## 质量标准
- 报价单独立完整，客户不需要追问细节
- 每项费用都能追溯到计算依据
- 价格梯度合理，鼓励大量采购
- 有效期和付款条件清晰

## 进阶：竞争性报价
如果是投标或竞争激烈的询盘：
1. **参考市场价**：先用 alibaba-intl 查同类产品的价格区间
2. **突出优势**：认证、交期、售后，不只拼价格
3. **灵活付款**：分期付款、赊销（老客户）可能比价格更有吸引力
