# 外贸市场分析

## 适用场景
开拓新市场、产品出海、市场进入决策、投资可行性分析。

## 与 market-research 的分工
`market-research` 侧重**市场规模测算**（TAM/SAM/SOM），这份侧重**外贸特定维度**：
- 目标国家/地区的市场准入
- 国际竞争格局
- 价格定位策略
- 贸易壁垒与合规

两者可以结合使用：先用 `market-research` 算规模，再用这份做进入策略。

## 分析框架（固定五大模块）

### 1. 市场规模与趋势
用 `web_search` + `fetch_url` 查询：
- **市场容量**：目标国该品类的年进口额/消费额
- **增长率**：过去 3 年 CAGR，未来 3-5 年预测
- **主要进口来源国**：中国占比多少，主要竞争国是谁

**数据来源优先级**：
1. 官方统计（UN Comtrade、目标国海关、商务部）
2. 行业协会报告
3. 市场研究机构（Statista、Euromonitor、IBISWorld）

**必须标注时间**："2025 年美国市场规模 $X"，不要写"目前"。

#### 示例输出
```markdown
### 市场规模与趋势

**美国智能家居市场（2025）**
- 市场规模：$1,350 亿美元 [来源](https://example.com)
- CAGR (2023-2028)：11.2%
- 主要进口来源：中国 (42%)、越南 (18%)、墨西哥 (12%)

**细分品类：智能插座**
- 2025 年销售额：$18 亿美元
- 中国供应商市场份额：65%
- 主要销售渠道：Amazon (45%), 线下零售 (30%), 官网直销 (25%)
```

### 2. 竞品分析
**至少分析 5-8 家国际竞品**（不只是中国供应商）。

#### 对比维度
| 品牌 | 国家 | 价格区间 | 主打市场 | 渠道 | 一句话定位 |
|---|---|---|---|---|---|
| TP-Link Kasa | 中国 | $12-25 | 北美、欧洲 | 线上+线下 | 性价比王者，生态完善 |
| Belkin Wemo | 美国 | $25-50 | 北美 | Apple Store | 高端定位，HomeKit 深度集成 |
| Philips Hue | 荷兰 | $30-60 | 全球 | 专卖店 | 照明巨头，品牌溢价高 |
| ... | ... | ... | ... | ... | ... |

**中国供应商的典型定位**：
- 白牌 ODM：$3-8，量大价优，无品牌
- 自有品牌：$8-18，尝试建立品牌，性价比路线
- 高端路线：$20+，少数，拼设计和功能

**用 alibaba-intl 验证价格区间**：
```javascript
// 搜索同类产品的供应商报价
searchProducts({ keyword: "smart plug", page: 1 })
```
拿到 FOB 价后，加运费、关税、渠道成本，推算零售价。

### 3. 目标客户画像
外贸的"客户"有两层：
1. **B 端（直接客户）**：进口商、分销商、零售商、电商平台
2. **C 端（终端用户）**：实际购买并使用产品的消费者

#### B 端客户分析
```markdown
**主要客户类型**：
- 电商平台卖家：在 Amazon/eBay 开店的中小卖家，单次采购 500-5000 件
- 大型零售商：Walmart/Target，需要 UL/FCC 认证，订单 10 万+，账期长
- 专业进口商：有仓储和分销网络，要求稳定供货，利润率 20-35%

**决策因素（优先级）**：
1. 价格与 MOQ（78% 最关注）
2. 认证齐全度（65%）
3. 交期稳定性（58%）
4. 售后支持（45%）
```

#### C 端用户画像（影响产品设计）
- 年龄：25-45 岁科技爱好者
- 收入：中产家庭（年收入 $50k-150k）
- 痛点：设置复杂、兼容性差、隐私担忧
- 偏好：简洁设计、语音控制、APP 易用

### 4. 价格策略
**三步定价法**：

#### Step 1: 成本倒推最低价
```
FOB 成本 = 材料 + 人工 + 制造费用 + 利润 (10-15%)
      $3.50

落地成本 = FOB + 海运 ($0.20) + 关税 (美国 7.5%) + 清关 ($0.30)
       ≈ $4.30

渠道成本 = 分销商加价 (30%) + 零售商加价 (40%)
零售价 ≈ $4.30 × 1.3 × 1.4 = $7.83

建议零售价：$7.99-9.99
```

#### Step 2: 对标竞品价格区间
```
低端：$5-10 (白牌、中国品牌)
中端：$10-20 (TP-Link、小米等)
高端：$20-50 (Belkin、Philips)

我们的定位：$8-12 (中低端，冲击性价比)
```

#### Step 3: 差异化定价
如果有独特功能（如能耗监测、USB 充电口），可加价 15-30%。

**用 exchange-rate 插件转换为目标市场货币**：
```javascript
convert({ amount: 9.99, from: "USD", to: "EUR" })
// 输出：€9.20，英国市场标 £8.49
```

### 5. SWOT 分析（针对该市场）

#### Strengths 优势
- 生产成本低 40-60%（中国制造优势）
- 供应链成熟，交期稳定
- ODM/OEM 能力强，可快速定制

#### Weaknesses 劣势
- 品牌认知度低
- 售后服务网络薄弱（时差、语言）
- 质量认知偏见（"Made in China" 刻板印象）

#### Opportunities 机会
- 智能家居市场高速增长（11%+ CAGR）
- 疫情后线上销售占比提升
- 大型零售商寻求平价替代品

#### Threats 威胁
- 关税政策不稳定（美国对华加征关税风险）
- 本土品牌崛起（越南、墨西哥制造）
- 技术门槛降低，竞争加剧

**每个点必须具体到这个市场、这个产品**，不要写"竞争激烈""市场广阔"这类空话。

### 6. 进入壁垒与合规要求
**关键认证**（按目标市场）：
| 市场 | 必需认证 | 周期 | 费用 | 备注 |
|---|---|---|---|---|
| 美国 | FCC, UL | 6-8 周 | $3k-8k | UL 非强制但大客户要求 |
| 欧盟 | CE, RoHS | 4-6 周 | $2k-5k | 需欧盟代表 |
| 日本 | PSE | 8-10 周 | $5k-10k | 门槛高，认证严格 |
| 澳洲 | RCM | 4-6 周 | $2k-4k | 认可 CB 报告可快速转 |

**关税**：
```markdown
美国 HS Code 8536.69（插座）：
- 基础税率：2.7%
- 301 关税（对华）：+25%
- 实际税率：27.7%

规避策略：
1. 转口（越南/墨西哥组装，降至 5-10%）
2. 保税仓（延迟缴税，改善现金流）
3. 价格调整（关税成本转嫁 or 自己吸收）
```

**知识产权风险**：
- 检索是否有外观设计专利冲突
- 商标注册（防止被抢注）
- 避免侵权爆款（如仿 Dyson、仿 Apple）

### 7. 进入策略建议
基于以上分析，给出可执行的建议：

```markdown
## 市场进入建议

### 推荐进入模式：先线上，再线下
1. **第一阶段（0-6 月）**：Amazon FBA + 独立站
   - 目标：测试市场反应，积累评价
   - 投入：首批货值 $20k，FBA 物流 $5k，推广 $10k
   - 风险：低；随时可撤

2. **第二阶段（6-18 月）**：拓展 eBay、Walmart 线上
   - 目标：月销 5000 件，建立品牌认知
   - 需完成：UL 认证、商标注册

3. **第三阶段（18月+）**：接触线下大客户
   - Target、Home Depot 等，需账期 60-90 天

### 价格定位：$9.99（中低端）
- 对标 TP-Link ($12-15)，价格低 20%
- 保持 FOB $3.50，到岸成本 $4.30，渠道利润空间 55%

### 首年目标
- 销量：50,000 件
- 收入：$500k
- 市场份额：<0.1%（先活下来）

### 关键风险与应对
- **风险 1**：关税政策变化 → 预留 10% 价格调整空间
- **风险 2**：认证延期 → 提前 3 个月启动认证
- **风险 3**：Amazon 差评 → 首批发给测评人，积累好评后再推

### 不建议
- ❌ 直接进 Costco/Target（门槛高，账期长，不适合首次）
- ❌ 价格战到 $5.99（利润消失，质量难保）
- ❌ 同时开拓 5 个市场（资源分散）
```

## 红线
- **不编造数据**：市场规模、关税税率必须有来源，查不到就写"未查到公开数据"
- **不空谈战略**："差异化竞争""品牌建设"这类不落地的话少说，要给出具体动作
- **不忽略合规**：没有 FCC 就想卖美国，这种方案不能出
- **不盲目乐观**：市场大不等于你能吃到，份额预测要保守

## 质量标准
- 每个结论都能追溯到数据或逻辑推理
- SWOT 的每一点都具体到该产品该市场
- 价格策略有完整的成本计算
- 进入建议可直接作为执行计划
- 风险清单覆盖合规、财务、运营三个层面

## 可选：用图表增强

## 进阶：多市场对比
如果同时评估多个目标市场（如美国 vs 欧洲 vs 日本），做横向对比表：

| 维度 | 美国 | 欧盟 | 日本 |
|---|---|---|---|
| 市场规模 | $135B | €98B | ¥1.2T |
| 增长率 | 11% | 9% | 6% |
| 关税 | 27.7% | 2.7% | 0% |
| 认证难度 | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 推荐进入顺序 | 1️⃣ | 2️⃣ | 3️⃣ |

**给出优先级排序和理由**，不要三个市场都说"值得进入"。
