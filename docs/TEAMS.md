# 专家团队使用指南

本文档介绍 OpenWorkBuddy 中的外贸专家团队，帮助你快速了解各团队的职责、适用场景和使用方法。

## 什么是专家团队

专家团队是由多位专家按特定顺序接力完成任务的协作组。每位专家完成自己的部分后，将结果和产出文件传递给下一位。你只需一句话委派给团队，系统会自动协调各专家按顺序执行。

---

## 外贸专家团队

### 1. 外贸出口全流程

**团队成员**（按执行顺序）：
1. 产品分析师
2. 国际采购专家
3. 外贸合规专家
4. 外贸销售专家
5. 国际物流专家

**适用场景**：
- 新产品出口到新市场，需要完整的流程规划
- 从零启动一个外贸项目
- 需要全面评估产品出口可行性

**工作流程**：
1. **产品分析师**：评估目标市场需求、竞争态势、定价策略，给出市场进入建议
2. **国际采购专家**：筛选供应商、对比价格和质量、给出采购方案
3. **外贸合规专家**：核查认证要求、海关政策、贸易管制，列出合规清单
4. **外贸销售专家**：制定客户开发策略、准备报价单和商务邮件模板
5. **国际物流专家**：设计运输方案、测算运费、推荐货代

**使用示例**：
```
我想把智能手表出口到德国市场，帮我做一个完整的出口方案。

产品信息：
- 产品：智能运动手表
- 功能：心率监测、GPS、防水
- 目标价格带：50-80 美元
- 预计首单：500 台
```

**预期输出**：
- 德国智能手表市场分析报告（需求、竞争、定价）
- 供应商对比表（3-5 家候选）
- 合规检查清单（CE 认证、REACH、海关申报）
- 客户开发方案（开发信模板、报价单）
- 物流方案对比（海运/空运、运费、时效）

---

### 2. 供应商评估团

**团队成员**（按执行顺序）：
1. 国际采购专家
2. 外贸合规专家

**适用场景**：
- 需要快速筛选和评估供应商
- 对已有供应商做合规审查
- 比较多个供应商的综合实力

**工作流程**：
1. **国际采购专家**：从多个平台搜索供应商，建立对比维度表（价格、MOQ、交期、认证、客户评价），给出 2-3 家推荐
2. **外贸合规专家**：核查推荐供应商的认证资质、贸易记录、合规风险，给出风险评级和应对建议

**使用示例**：
```
帮我找 3 家做蓝牙耳机的供应商，要求：
- 有 CE 和 FCC 认证
- MOQ 在 1000 台以内
- 交期 30 天内
- 主要出口欧美市场
```

**预期输出**：
- 供应商对比表（包含价格、MOQ、交期、认证、成立年限、主要客户）
- 推荐排序（性价比最优/质量最稳/交期最快）
- 合规风险评估（认证有效性、贸易管制、历史记录）
- 下一步建议（索样/验厂/试单）

---

### 3. 市场进入团

**团队成员**（按执行顺序）：
1. 产品分析师
2. 外贸合规专家
3. 国际物流专家

**适用场景**：
- 评估新市场的进入可行性
- 快速了解市场准入门槛
- 在多个目标市场中做选择

**工作流程**：
1. **产品分析师**：分析目标市场需求规模、增长趋势、竞争格局、价格定位，给出市场优先级建议
2. **外贸合规专家**：列出该市场的准入要求（认证、关税、进口许可）、贸易壁垒、合规成本
3. **国际物流专家**：评估物流可达性、运输成本、时效、清关难度

**使用示例**：
```
我想把家用空气净化器出口，帮我分析美国、德国、日本三个市场，哪个最适合先进入？

产品信息：
- 产品：家用空气净化器
- CADR 值：300 m³/h
- 价格定位：中高端
- 首单预算：10 万美元
```

**预期输出**：
- 三国市场对比分析（需求规模、增长率、竞争强度、价格带）
- 准入门槛对比表（认证要求、关税、进口限制、合规成本）
- 物流方案对比（运输时效、运费、清关难度）
- 市场进入建议（推荐优先进入哪个市场、原因、预期投入和回报周期）

## 使用技巧

### 如何委派给专家团队

在对话中直接说明需求即可，例如：
- "用外贸出口全流程团队帮我做个方案"
- "委派给供应商评估团"
- "让市场进入团分析一下这几个市场"

### 提供充分的背景信息

团队工作质量取决于你提供的信息。建议包含：
- **产品信息**：品名、规格、功能、价格定位
- **目标市场**：具体国家或地区
- **业务目标**：首单规模、预算、时间要求
- **已知条件**：现有供应商、认证情况、物流渠道

### 中途调整

如果某个专家的输出不符合预期，可以：
- 要求该专家重新执行："产品分析师，请重点分析 25-35 岁女性用户"
- 跳到特定专家："直接让外贸合规专家做合规检查"

### 保存和复用

团队产出的文档和数据可以：
- 导出为 Word/Excel/PDF
- 作为下次决策的输入
- 分享给团队成员协作

## 常见问题

**Q: 团队执行需要多长时间？**  
A: 取决于任务复杂度和需要搜索的信息量。一般外贸出口全流程需要 10-15 分钟，供应商评估团 5-8 分钟，市场进入团 8-12 分钟。

**Q: 可以只用团队中的某几位专家吗？**  
A: 可以。你可以单独委派给某位专家，或者明确说明"只需要前 3 位专家"。

**Q: 团队输出的数据来源可靠吗？**  
A: 所有数据都会标注来源和时间。关键数据会交叉验证。但商业决策前建议再次核实最新信息。

**Q: 团队能处理非标准的特殊需求吗？**  
A: 专家团队主要处理标准流程。非标需求建议单独委派给对应专家，并详细说明要求。
