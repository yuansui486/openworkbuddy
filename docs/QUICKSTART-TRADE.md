# 外贸场景快速开始

本指南帮助外贸从业者快速上手 OpenWorkBuddy，用 AI 专家团队解决日常工作中的实际问题。

---

## 5 分钟快速体验

### 场景 1：找供应商

**你的需求**：找做无线充电器的供应商

**怎么说**：
```
帮我找 3 家做无线充电器的供应商，要求：
- 功率 15W 以上
- 有 Qi 认证
- MOQ 500 台以内
- 主要出口欧美
```

**谁来干活**：供应商评估团（国际采购专家 + 外贸合规专家）

**你会得到**：
- 3-5 家候选供应商对比表
- 价格、MOQ、交期、认证情况
- 合规风险评估
- 推荐排序和理由

---

### 场景 2：写开发信

**你的需求**：给美国客户写一封产品推介邮件

**怎么说**：
```
我要给美国的户外用品零售商写开发信，推我们的便携式太阳能充电板。

产品卖点：
- 20W 快充，2 小时充满手机
- 防水防尘 IP67
- 重量只有 400g
- 价格比同类产品低 15%
```

**谁来干活**：外贸销售专家

**你会得到**：
- 英文商务邮件（主题 + 正文）
- 一个简短版备选
- 产品卖点提炼
- 行动号召设计

---

### 场景 3：算运费

**你的需求**：比较几种运输方式的成本和时效

**怎么说**：
```
帮我算一下从深圳到洛杉矶的运费：
- 货物：蓝牙音箱 1000 台
- 单箱：40x30x25cm，10kg
- 总共 50 箱
- 要求 30 天内到港
```

**谁来干活**：国际物流专家

**你会得到**：
- 海运/空运/快递方案对比
- 每种方式的运费、时效、风险
- 整柜/拼箱建议
- 货代筛选建议

---

### 场景 4：查认证要求

**你的需求**：了解产品进入欧盟需要哪些认证

**怎么说**：
```
我的LED台灯要出口到德国，需要哪些认证？

产品信息：
- LED 护眼台灯
- 12V 适配器供电
- 带 USB 充电口
```

**谁来干活**：外贸合规专家

**你会得到**：
- 必需认证清单（CE、RoHS、REACH）
- 测试标准和周期
- 大概认证费用
- HS 编码和关税税率
- 申报注意事项

---

### 场景 5：市场调研

**你的需求**：判断新产品在某个市场有没有机会

**怎么说**：
```
帮我分析一下智能猫砂盆在日本市场的机会：
- 自动清理
- App 远程监控
- 健康数据记录
- 定价 150-200 美元
```

**谁来干活**：产品分析师

**你会得到**：
- 日本宠物用品市场规模和增长趋势
- 智能猫砂盆品类竞争格局
- 价格定位分析
- 目标用户画像
- 进入建议和风险提示

## 进阶场景

### 完整出口方案

**适合情况**：新产品 + 新市场，需要从头规划

**委派团队**：外贸出口全流程

**示例**：
```
用外贸出口全流程团队帮我做方案：

产品：便携式榨汁机
目标市场：美国
首单规模：2000 台
预算：5 万美元

需要包括：选品分析、供应商、合规、销售策略、物流方案
```

**产出**：
1. 市场分析报告（需求、竞争、定价）
2. 供应商对比和推荐
3. 合规检查清单（FDA、FCC、海关）
4. 客户开发方案（开发信、报价单）
5. 物流方案（海运/空运对比、运费）

**耗时**：约 15 分钟

---

### 供应商尽职调查

**适合情况**：已有几家候选供应商，需要深度评估

**委派团队**：供应商评估团

**示例**：
```
帮我评估这 3 家供应商，推荐最靠谱的：

1. 深圳市某某电子有限公司
   - 阿里国际站金牌供应商
   - 报价：单价 $12.5，MOQ 1000
   
2. 东莞某某科技有限公司
   - 成立 8 年
   - 报价：单价 $11.8，MOQ 2000
   
3. 中山某某实业有限公司
   - ISO9001 认证
   - 报价：单价 $13.2，MOQ 500

产品：蓝牙耳机，要出口欧盟
```

**产出**：
- 完整对比表（价格、资质、历史、风险）
- 认证有效性核查
- 贸易合规检查
- 推荐排序和理由
- 风险提示

---

### 多市场比较

**适合情况**：在几个目标市场中选一个先做

**委派团队**：市场进入团

**示例**：
```
我想出口智能门锁，帮我比较美国、英国、澳大利亚三个市场，推荐先做哪个？

产品信息：
- 指纹 + 密码 + 刷卡
- 支持 WiFi 远程控制
- 价格定位：中高端
- 首轮预算：10 万美元
```

**产出**：
- 三国市场对比（规模、增长、竞争）
- 准入要求对比（认证、关税、限制）
- 物流方案对比（运费、时效、难度）
- 市场进入建议（优先级 + 理由 + 投入预估）

## 常见问题 FAQ

### 关于使用

**Q: 我是外贸新手，完全不懂，能用吗？**  
A: 可以。把你的真实需求说出来就行，专家会引导你补充必要信息。从简单场景开始（找供应商、写邮件），逐步熟悉。

**Q: 专家给的信息准确吗？**  
A: 所有数据都会标注来源和时间。关键决策前建议再次核实最新政策和价格。认证要求、海关政策等以官方渠道为准。

**Q: 可以用中文交流吗？**  
A: 可以。你用中文提需求，专家会根据场景输出中文或英文。比如开发信会给英文版，市场分析会给中文报告。

**Q: 一次任务要花多少钱？**  
A: 单个专家任务通常 2-5 分钟，团队任务 5-15 分钟。具体消耗取决于任务复杂度和需要搜索的信息量。

---

### 关于输出

**Q: 专家输出的文档可以直接用吗？**  
A: 大部分可以。报价单、开发信、市场分析报告可以在专家输出基础上微调后使用。但合同、认证申请等正式文件建议找专业机构复核。

**Q: 数据来源是哪里？**  
A: 专家会从多个来源搜索信息：阿里巴巴国际站、Google Trends、海关数据、官方政策文件、行业报告。每条关键数据都会注明来源。

**Q: 专家能帮我直接下单或联系供应商吗？**  
A: 不能。专家只提供信息和建议，实际的商务操作（下单、签约、付款）需要你自己完成。

**Q: 输出的内容可以导出吗？**  
A: 可以。对话记录可以导出，文档可以保存为 Word/PDF/Markdown，表格可以保存为 Excel。

---

### 关于专家能力

**Q: 专家能处理小语种市场吗？**  
A: 目前主要支持英语市场（美国、英国、澳大利亚等）和部分主流市场。小语种市场的信息可能不够全面。

**Q: 专家懂我的行业吗？**  
A: 专家掌握外贸通用流程和常见品类。非常专业的行业术语和冷门品类可能需要你补充背景信息。

**Q: 能帮我谈价格吗？**  
A: 外贸销售专家可以提供谈判策略和让步建议，但具体谈判还是要你来。专家会告诉你底线在哪、能让多少、怎么换条件。

**Q: 认证要求会变吗？**  
A: 会。各国认证政策会更新。专家给出的是当前信息，正式申请前建议查询最新官方要求或咨询认证机构。

---

### 关于费用和合规

**Q: 专家能帮我避税或走灰色通道吗？**  
A: 不能也不会。专家严格遵守合规原则，只提供正规合法的建议。任何违规操作的要求都会被明确拒绝。

**Q: 专家会泄露我的商业信息吗？**  
A: 不会。对话内容仅你可见，专家不会将你的信息用于其他用途。但涉及高度敏感的商业机密时，建议脱敏处理。

**Q: 专家的建议出错了，谁负责？**  
A: 专家提供的是信息参考和决策辅助，不构成法律或商业承诺。最终决策和执行风险由你自己承担。重大决策建议咨询专业机构。

## 使用技巧

### 1. 提供具体信息

❌ 不好的提问：
> "帮我找供应商"

✅ 好的提问：
> "帮我找做蓝牙音箱的供应商，要求有 FCC 认证，MOQ 1000 台以内，主要出口美国"

### 2. 明确你的目标

说清楚你要达成什么：
- "我要在 3 个月内出第一单"
- "我要找性价比最高的供应商"
- "我要判断这个产品值不值得做"

### 3. 分步骤推进

复杂任务可以拆解：
1. 先让产品分析师评估市场
2. 确认值得做后，再找供应商
3. 供应商定了，再做合规检查
4. 最后设计销售和物流方案

### 4. 追问细节

专家输出后可以继续追问：
- "德国的 CE 认证具体怎么办？"
- "这个供应商的价格还能再谈吗？"
- "海运和空运各有什么风险？"

### 5. 保存重要信息

把关键产出保存下来：
- 供应商对比表（下次采购复用）
- 认证清单（同类产品通用）
- 开发信模板（调整后批量使用）
- 市场分析报告（给老板汇报）
